# Reestar – Food Order Website

Reestar is a simple and responsive food ordering website built using **HTML and CSS**. The website provides a clean and user-friendly interface for browsing food items and placing an order.

## Features

* 🍔 Attractive food menu layout
* 🛒 Simple food ordering interface
* 📱 Responsive and clean design
* 🎨 Styled using basic CSS
* 📄 Easy-to-use navigation

## Technologies Used

* HTML5
* CSS3

## Project Purpose

This project was created to practice **HTML structure, CSS styling, page layout, and responsive web design** while building a simple food ordering website.

## Pages

* **Home** – Displays the food menu and available dishes.
* **Contact** – Provides contact information for users.

## Author

Developed as a beginner-friendly web development project to improve frontend development skills.
